# 🚀 Ingeniería de Software con Visión 3D | Portafolio Personal

¡Bienvenido! Este es el repositorio de mi portafolio profesional, donde combino mi experiencia en backend (**Java/Spring Boot** y **.NET**) con mi pasión por las interfaces interactivas y escalables.

> "No se trata de saberlo todo, sino de tener la agilidad para aprender y resolver cualquier reto técnico."

## 🛠️ Ecosistema Técnico

Este portafolio no es solo una landing page; es una aplicación conectada a la **API de GitHub** que renderiza mis proyectos en tiempo real.

- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla).
- **Consumo de Datos:** Fetch API para integración dinámica con GitHub.
- **Visual:** Google Materials Symbols & Public Sans Typography.
- **Despliegue:** GitHub Pages con flujo de integración continua.

## 🌟 Características Principales

- **Dashboard de Repositorios:** Carga dinámica de proyectos propios (excluyendo forks) con detección automática de lenguaje principal.
- **Dark Mode Nativo:** Adaptación visual basada en las preferencias del sistema del usuario.
- **Sección AR Shop:** Muestra de mi iniciativa de digitalización local en Santa Ana, El Salvador.
- **Optimizado para SEO:** Metaetiquetas configuradas para máxima visibilidad en LinkedIn y buscadores.
